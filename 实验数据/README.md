## 新增数据归档规则

新实验按 `实验数据/API测量/实验编号/` 建立目录，内含 `raw/`、`setup/`、`processed/`、`models/` 和事件、窗口记录。尚无真实数据时不建立空实验结果，结构示例见 [API 实验步骤](../实验操作/API测量/README.md)。

原文件只归档，清洗、修正、对齐和模型结果另存。记录真实开始/结束时间、分段文件零点关系、通道、单位、运动和冷却事件。API 与旧三探头数据的标定及测量点不同，不直接合并为同一正式对照。
