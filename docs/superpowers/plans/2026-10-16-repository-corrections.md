## 2. Global Constraints（统一约定）

- A＝床身、B＝立柱、C＝横梁，各两支路；八组合0/A/B/C/AB/AC/BC/ABC。保留18路温度，包含环境与主轴通道。
- 一个共享串口由一个通信管理器持有。地址唯一性以“同一物理总线上的不同物理设备”为判断单位，不以信号行数判断。
- 运行期间保留原始探头，XYZ仅来自主轴停转、同向到位、独立角向复位后的有效稳定窗口。角向复位不得通过让三探头读数回初值实现。
- 每轮实验只建立一次冷态基准，冷却与基准启动先后在各组统一。实测标定文件零位和每轮基准分别保存。
- 正式XYZ差值拟统一为“当前减本轮基准”，保留既有有符号实测C的拟合约定；原型等价迁移详见R10，不直接翻转实测矩阵。
- 实际UTC、单调经过时间、模拟模型时间分别保存；失败、缺失、超程和位姿失效保留原因，不填成零位移。
- 指令与实际反馈分列；没有真实开度、流量或水温反馈时明确缺失／人工来源，不能用模型或指令代替实测输入。
- 测量输出保留主轴等热影响；Shapley分配的是三区冷却对整体相对位移的改善。贡献权重不直接作为控制增益。
- 第一阶段固定冷却组合；完成测量验证、固定对照和动态辨识后，才研究间歇位移反馈。
- 不猜测真实站号、寄存器、波特率、阀门单位、等待窗口、断通信动作、PID增益或允许样本龄期。

## 3. Review Focus（验收重点）

1. 采集中途超时／丢帧／超程：保留真实时间和失败来源，窗口不得靠后续成功点凑成有效。
2. 同轮再次归零／通信恢复：原基准不变，恢复后必须重新确认位姿。
3. 越界阀指令／写入失败／无反馈：请求、限幅、编码、写入结果与反馈可区分，不能冒充真实动作。
4. 实机连接失败／旧值回填：真实实验不得自动生成模拟数据；旧值有原时刻和龄期。
5. 标定约定迁移：解码与依赖C的模拟前向同步核对，测试完整链路而非只做一次矩阵等式。

3. 核实所有设备是否支持同一组波特率/校验/停止位。不同物理设备在同一总线上地址唯一；同一物理设备的多个信号允许共享从站号，靠寄存器区分。

**问题及影响：** 旧程序百分比/角度表述和60/90上限不统一。例如输入90，实际下发值被截至6000，日志仍为90；不能据此认定6000代表现场60%或60°。

**修正方法：**
1. 依据设备说明和实测冻结工程单位、上下限及寄存器编码。分开定义requested、clamped、register_value、write_result、feedback及其时间。
