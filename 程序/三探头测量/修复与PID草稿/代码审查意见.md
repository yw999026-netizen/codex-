## ⚠️ 需要优化的问题

### 问题1: Modbus通讯可靠性不足

**现状** (第1958-1988行):
```matlab
% 直接读取，没有重试
rawTemp = read(m, 'holdingregs', tempRegister, n, slave);
```

**问题**:
- 单次通讯失败就跳过数据点
- 没有校验和 (CRC)
- 没有超时自动断线重连

**优化方案**:
```matlab
function [tempVals, success] = readAllSensorsWithRetry(maxRetry)
    tempVals = [];
    success = false;
    
    for attempt = 1:maxRetry
        try
            % 读取逻辑...
            success = true;
            return;
        catch ME
            if attempt < maxRetry
                pause(0.1);  % 等待100ms后重试
            else
                warning('读取失败:%s', ME.message);
            end
        end
    end
end
```

### 问题3: 电涡流传感器数据格式转换简化

**现状** (第2027-2041行):

**问题**:
- 假设传感器输出是标准16位有符号整数

**优化方案**:
```matlab

function value = convertProbeData(raw, dataType, scale)
    switch dataType
        case 'int16'
            value = typecast(uint16(raw), 'int16');
        case 'uint16'
            value = double(raw);
        case 'float32'
            value = typecast(uint32(raw), 'single');
    end
    value = double(value) * scale;
end
```

### 问题4: 定时器可能掉帧

**现状** (第1209-1224行):
```matlab
acqTimer = timer(...
    'ExecutionMode', 'fixedRate', ...
    'Period', sampleIntervalSec, ...
    'StartDelay', sampleIntervalSec, ...
    'BusyMode', 'drop', ...  % 繁忙时丢弃回调
```

**问题**:
- `BusyMode='drop'` 会丢弃采样点

```matlab
acqTimer = timer(...
    'BusyMode', 'queue', ...     % 改为queue，积压而不丢弃
    'MaximumSpikes', 10, ...     % 最多积压10个
    ...);

% 在acquisitionTick中检测
if sampleIndex < expectedIndex
    warning('检测到掉帧: 期望%d, 实际%d', expectedIndex, sampleIndex);
```

### 改进1: 重试机制

```python
# Python版本
def read_modbus_with_retry(client, slave_id, address, count, max_retry=3):
    for attempt in range(max_retry):
        try:
            response = client.read_holding_registers(
                address=address,
                count=count,
                slave=slave_id
            )
            if not response.isError():
                return response.registers
        except Exception as e:
            logging.warning(f"尝试{attempt+1}/{max_retry}失败: {e}")
            if attempt < max_retry - 1:
                time.sleep(0.1)
    
    raise ConnectionError(f"读取失败: 从机{slave_id}, 地址{address}")
```

### 改进2: 严格时间网格

```python
# 保证采样点是精确的 0, 2, 4, 6... 秒
class StrictTimedSampler:
    def __init__(self, sample_interval):
        self.sample_interval = sample_interval
        self.sample_index = 0
        self.start_time = time.time()
    
    def get_next_sample_time(self):
        self.sample_index += 1
        return self.sample_index * self.sample_interval
    
    def should_sample_now(self):
        elapsed = time.time() - self.start_time
        expected_time = self.sample_index * self.sample_interval
        return elapsed >= expected_time
```

### 改进3: 数据质量评估

```python
def assess_probe_quality(probe_buffer, threshold_jump=10):
    """
    评估探头数据质量
    返回: (质量评分, 异常描述)
    """
    if probe_buffer.shape[1] < 2:
        return 100, "数据点太少"
    
    # 计算相邻采样点的差异
    diffs = np.abs(np.diff(probe_buffer, axis=1))
    max_jump = np.max(diffs)
    
    if max_jump > threshold_jump:
        return 50, f"检测到跳跃: {max_jump:.1f}μm"
    
    # 计算稳定性 (标准差)
    stds = np.std(probe_buffer, axis=1)
    if np.any(stds > 5):
        return 75, f"数据波动较大: σ={stds}"
    
    return 100, "优秀"
```
