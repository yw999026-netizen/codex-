# 机床分区冷却的热误差抑制贡献分析与间歇反馈控制研究

更新日期：2026-10-13。

文档状态：研究方案与论文写作草稿。分区贡献分析、动态辨识和闭环控制效果均为拟开展的研究内容；本文不报告新增实验结果。

## 1. 研究目标

针对机床热变形引起的刀具侧相对工作台位移，本研究拟以立柱、横梁和床身为分区冷却对象，研究不同冷却组合对固定测量位姿下三维热位移的影响，量化各区域对联合冷却抑制效果的归因贡献。在此基础上，通过冷却动态响应辨识，构建以三维相对热位移为反馈、以各区域球阀开度为控制输入的闭环调节策略，并评价其热误差抑制效果。

总体研究路线为：

**热位移测量与有效性验证 → 分区冷却对照试验 → 抑制贡献分析 → 冷却动态响应辨识 → 间歇反馈控制 → 抑制效果验证。**

## 2. 研究方法与技术路线

### 2.1 三维相对热位移测量

拟采用基于R-test原理的三电涡流测量系统，通过实测标定矩阵将探头读数变化转换为三维相对位移。通过统一检测坐标、主轴角向位置及停转后的测量流程，建立相对于冷态基准的热位移测量方法。同步记录结构温度、实际采样时间及测量状态，为冷却效果分析和动态辨识提供数据基础。

设本轮实验冷态三路探头基准为 \(\mathbf p_0\)，第 \(k\) 次有效回测窗口的三路平均读数为 \(\overline{\mathbf p}_k\)，实测转换矩阵为 \(C\)，则：

$$
\Delta\mathbf x_k=C\left(\overline{\mathbf p}_k-\mathbf p_0\right),
\qquad
\Delta\mathbf x_k=
\begin{bmatrix}\Delta X_k&\Delta Y_k&\Delta Z_k\end{bmatrix}^{\mathsf T}.
$$

探头读数与位移统一使用明确的物理单位。本轮冷态基准与标定文件中的标定零位分别保存；后续回测使用同一本轮基准。

主轴角向复位应以独立角度基准为依据，并验证其重复性。运行期间测球离开有效测量位置时，探头原始读数可保留用于追溯，但不作为有效刀尖热位移。回测需登记主轴停转、检测位到位、角向复位完成及采样窗口起止时刻。

### 2.2 分区冷却对照试验

拟采用三因素两水平的全因子冷却试验设计。以立柱、横梁和床身分别为因素 \(A\)、\(B\)、\(C\)，设置无冷却、单区域冷却、双区域联合冷却及三区域联合冷却等八种工况。

| 工况 | 开启水冷的区域 |
| --- | --- |
| 0 | 全部关闭 |
| A | 立柱 |
| B | 横梁 |
| C | 床身 |
| AB | 立柱、横梁 |
| AC | 立柱、床身 |
| BC | 横梁、床身 |
| ABC | 立柱、横梁、床身 |

在初始热状态、机床运行程序、支路冷却参数及回测节拍可比的条件下，开展独立重复试验。各已开启区域采用预先规定的冷却设定，记录实际流量和进出水温；组合变化时核查支路条件是否保持可比。统一冷态基准建立、水冷启动及停机恢复过程的操作规则，并记录环境与热历史。

独立重复以一次完整热循环为单位。单次实验中的连续采样点和窗口内读数不作为独立实验重复。

### 2.3 热误差抑制贡献分析

拟依据预先选定的热位移评价指标，分析各冷却组合的改善效果。保留X、Y、Z带符号位移曲线，分别计算每次独立实验的评价指标，再汇总各工况结果及其不确定性。

设无水冷工况的误差指标为 \(E_0\)，冷却组合 \(S\) 的同一指标为 \(E_S\)，则改善量为：

$$
I_S=E_0-E_S.
$$

当 \(E_0>0\) 时，改善率定义为：

$$
\eta_S=\frac{E_0-E_S}{E_0}\times100\%.
$$

若需要将三区联合冷却的总改善分配给各区域，拟采用平均边际贡献方法，即Shapley分配。该方法利用八组工况结果，平均各区域在不同其他区域冷却状态下加入时带来的改善量。计算中的加入顺序不表示在一次连续升温实验中依次开启区域。

以立柱为例：

$$
\phi_A=
\frac{E_0-E_A}{3}
+\frac{(E_B-E_{AB})+(E_C-E_{AC})}{6}
+\frac{E_{BC}-E_{ABC}}{3}.
$$

横梁、床身的贡献同理，满足：

$$
\phi_A+\phi_B+\phi_C=E_0-E_{ABC}.
$$

当联合冷却总改善明确为正且明显大于实验不确定性时，归因贡献权重为：

$$
w_i=\frac{\phi_i}{E_0-E_{ABC}}\times100\%.
$$

负贡献保留并解释；总改善接近零或不确定性较大时，优先报告绝对贡献及其不确定性，不强行换算百分比。联合效果的不叠加可能来自温度场交互、位移抵消或评价指标的非线性，具体热耦合解释需结合温度场证据。

### 2.4 冷却动态响应辨识

为建立控制输入与热位移响应之间的关系，拟进一步开展分区球阀开度变化试验，同步记录阀门指令、可获得的实际开度、冷却流量、水温、结构温度及三维热位移。通过动态响应辨识，确定各区域冷却对不同位移方向的作用符号、响应幅度、时滞及交叉影响，为控制器设计提供依据。

先在一致的机床运行—回测循环下改变一个区域的冷却输入，其余区域保持既定设置；随后通过重复、不同输入水平及联合动作检验模型。供水条件和实际流量需同时记录，球阀开度不直接等同于冷却能力。

贡献分析结果用于确定重点控制区域，动态辨识结果用于确定阀门调节规律。归因贡献百分比不直接作为阀门开度、控制增益或位移方向反馈。

### 2.5 间歇位移反馈控制

考虑到位移测量仅在主轴停转并返回固定检测位姿后有效，拟采用间歇测量反馈控制方式。在每次有效测量窗口结束后，根据带符号热位移反馈更新各区域冷却设定，并在相邻测量之间保持控制指令。控制策略设计将考虑冷却响应延迟、区域间交叉影响及阀门开度约束，以降低既定测量条件下的三维相对热位移。

计划先建立作用方向明确的单区域、主要误差方向控制基线，再根据动态辨识结果研究多区域协调控制。具体控制算法、参数和更新周期依据实测响应确定，不预先宣称三个方向均可独立控制或严格归零。

后续可研究利用连续温度数据估计运行期间的热位移，并以间歇实测进行校正；此扩展需独立验证预测精度及闭环抑制效果。

### 2.6 控制效果验证

拟通过无水冷、固定开度冷却和闭环调节冷却的对照试验，比较相同运行与回测条件下的热位移峰值、均方根值及重复间波动，并结合冷却用量和阀门调节过程评价控制效果。

热位移指标采用有效回测窗口的代表值，并规定共同评价时段。回测间隔不一致时，预先明确实际时间加权等处理方法，不将离开测量位置时的探头读数纳入热误差指标。

控制效果评价以所测试工况、冷却参数及固定测量位姿下的热位移为依据。持续加工过程中的误差改善与加工精度提升，需运行期独立测量或加工试验支持。

## 3. 论文术语与结论范围

| 日常表达 | 论文中采用的表述 |
| --- | --- |
| 刀尖偏了多少 | 固定测量位姿下的三维相对热位移 |
| 哪个部件贡献大 | 各冷却区域对联合热误差抑制效果的归因贡献 |
| 阀门开大后有什么变化 | 球阀开度变化引起的热位移动态响应 |
| 根据漂移量调阀门 | 基于间歇热位移反馈的分区冷却闭环调节 |
| 水冷把误差压下去 | 通过分区冷却调节实现热误差主动抑制 |

本研究的归因权重依赖运行工况、冷却参数、测量位姿及评价指标，不解释为结构区域固有不变的热变形贡献。当前控制方式表述为间歇位移反馈控制。
