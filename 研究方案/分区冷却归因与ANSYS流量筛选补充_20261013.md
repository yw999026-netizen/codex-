## 3. 先定义冷却水平，再开展八组合试验

### 3.1 三因素与六执行器的关系

| 工况 | A 床身 | B 立柱 | C 横梁 |
| --- | :---: | :---: | :---: |
| 无分区水冷 | 0 | 0 | 0 |
| 床身 | 1 | 0 | 0 |
| 立柱 | 0 | 1 | 0 |
| 横梁 | 0 | 0 | 1 |

0 表示该区域分区冷却关闭，应检查残余流量；1 表示该区域两路采用同一组预先确定的开启设定。这里有三个二水平因素，因此是 2³＝8 个组合。若把六路阀门分别作为独立二水平因素，才是 2⁶＝64 个组合。

开启水平应具备可实现、可重复且可观测的热响应。无需事先保证每个区域、每个方向都改善热位移；负作用和交互作用同样是研究结果。也不能直接把任意中间角度、最大开度或相同开度当作最佳流量。

### 3.2 共用水泵下的两种试验策略

**固定开度策略：** 每个区域开启时，始终使用相同的一对阀门设定，并记录六路实际流量、水温及水泵状态。不同组合下实际流量可能因支路重新分配而变化。八组合仍可用于评价这套预先定义的阀门设置策略，其贡献包含共泵水力耦合产生的效果。

**固定流量策略：** 为各区域定义相同的目标流量对，在每种组合试验前调节阀门，使实际流量达到目标，并检查试验中能否保持。此时阀门设定可能随组合改变。只有具备并验证相应调节能力时，才可宣称保持了固定流量。

2026-10-13 曾以固定开度作为方案候选。根据 2026-10-14 最新确认的独立调节与支路设定保持能力，当前优先按固定目标流量及入口水温设计；各组合下核查实测值满足预定允许偏差，阀门开度可以为维持目标而变化。具体流量、水温仍待预试验确定，不把设定保持等同于无波动的实测恒定。若实际执行只能固定开度，应按真实执行策略解释，不能误标固定流量。

水力预试验应记录单路及典型联合开启时的开度—实际流量关系、其他支路流量变化、总流量与供水状态。由 ANSYS 得到的流量候选，需要通过这些实测关系转换成设备上的阀门设定。

## 4. 联合冷却归因贡献的定义

先选定一个数值越小代表热误差越小的评价指标 J，例如指定时段内有效窗口的某方向最大绝对位移、时间加权 RMS，或预先定义的三维位移指标。同时保留 XYZ 分方向结果，避免综合指标掩盖某方向恶化。指标反映这些窗口的观测响应；对间歇样本计算 RMS 时需说明加权或插值规则，不能据此宣称测得了运行期间未观测的连续漂移峰值。

设 N＝{A,B,C}，J(S) 为仅开启区域集合 S 时的指标，定义相对无分区水冷的抑制量：

**v(S)＝J(∅)−J(S)，且 v(∅)＝0。**

采用 Shapley 平均边际贡献，即对三个区域的六种加入顺序平均。以床身 A 为例：

**φA＝[v(A)−v(∅)]/3＋[v(AB)−v(B)]/6＋[v(AC)−v(C)]/6＋[v(ABC)−v(BC)]/3。**

B、C 同理，并满足 **φA＋φB＋φC＝v(ABC)**。这里不是对四种前置集合简单等权平均；集合大小对应的权重不同。

需要报告贡献的符号、单位、重复试验不确定性及指标定义。某区域的贡献可以为负，说明按该指标和设置策略平均加入它时使结果恶化。只有总抑制量明显为正且远离测量与重复波动时，才适合附加 φi/v(ABC) 的百分比解释；贡献不必都处于 0—100%。

这些贡献只适用于所测试的运行工况、冷却开启水平、水温条件、评价时段与检测位姿。它们与全因子主效应有关，但不等同于某个单区域的改善量，也不直接构成动态控制规律。

应开展按完整实验运行计算的独立重复，考虑热状态恢复、随机顺序或日期区组。窗口内多个采样点、同一次实验中的多个时间点都不能代替独立重复。回测时间不等间隔时，RMS 的时间权重或共同评价时点应预先说明；简单对全部窗口等权平均不等于连续时间 RMS。

## 5. ANSYS 的作用与建模路线

ANSYS 可以筛选具有物理依据的候选流量范围，之后由实机预试验修正。单次无水冷数据不能验证新增流道的换热能力，也不能直接给出可信的最优流量。

### 5.1 基准热模型

先建立不启用六路分区水冷的机床瞬态热模型。依据材料、接触和约束条件，在主轴、轴承、螺母等位置设置有物理约束的等效热源，用实测温度曲线校准少量有效发热或散热参数，再检查 XYZ 热位移。

不应把所有测点温度直接强制施加到结构上，再把这些点温度的一致当作模型预测准确。实测温度主要用于约束初始状态、校准和检查；环境温度可以作为随时间变化的外部换热边界输入。

热源功率与换热系数可能相互补偿，因此需要限制参数数量和合理范围。用于调参的数据与预留检查数据应区分；条件允许时以独立实验验证。用全部数据调参后得到的一致性属于校准结果，不是独立验证。

### 5.2 加入冷却流体域

在 Fluent 或 CFX 中计算水流与固体的共轭传热，将固体温度场导入 Mechanical，计算热膨胀及刀具侧相对工作台的 XYZ 位移。流体压力是否需要传递到结构，取决于它对变形的实际影响；通道几何几乎不受变形影响时，通常可先采用单向温度传递，不必默认建立双向流固耦合。

需要的输入包括：

- 实际六路流道/水冷套几何、固体与流体域及有效接触面积；
- 材料导热系数、密度、比热、热膨胀系数，必要时考虑温度依赖；
- 热源位置与加载历史、初始温度场、环境换热及接触热阻；
- 支撑、连接和运动部件位置，以及相对位移的输出定义；
- 各入口水温、流量或压力边界、出口与共用水泵的可实现供流条件。

仿真评价应以实验代表位置的相对热位移为主。结构最高温度降低或最大总变形降低，并不自动代表目标 XYZ 热误差改善。

### 5.3 筛选流量范围

1. 用无水冷数据检查基准模型的温升趋势与三向热位移。
2. 在供水温度尚未实测前，使用明确标注的水温假设做敏感性分析；取得实测入口水温后再收敛范围。
3. 可先固定区域内两支路的流量分配比例，扫描三个区域的总流量，之后检查左右/上下分配的敏感性。相同流量比例只是试验约定，不是天然最优分配。
4. 比较热位移指标、结构温差、响应速度、流量增大后的收益变化及各支路压降。
5. 检查共用水泵能否同时实现候选六路流量。给六个入口任意指定流量并不证明实物系统能达到。
6. 可用稳态结果粗筛，再用与实际运行—回测过程对应的瞬态分析评价最终候选。检查网格、时间步及温度场映射的稳定性。
7. 在实机上测量候选流量的实际水温、温升与热位移，验证冷却模型并选定正式开启水平。

是否过冷或冷却能力不足，应结合供水和结构温度、温度梯度、实际换热量与动态响应判断。位移变号、温差增大或热误差恶化只能提示进一步检查，不能单独判为过冷；未达到位移目标也可能来自交叉作用、目标不可达或暂态尚未结束，不能自动解释为冷却不足。

## 7. 后续热位移反馈控制的边界

用户的控制意图为：

**有效 XYZ 热位移 → 控制算法 → 六路球阀开度指令 → 实际流量与换热 → 下一次有效 XYZ 测量。**

不把自动流量内环作为既定前提。六路流量可用于辨识实际冷却输入、监测水力耦合及约束检查；是否加入流量内环属于后续设计选择。

如六个阀门分别参与控制，动态模型为六输入、三输出，需要辨识最多 18 条输入—输出关系及其可辨识性，不要求先完成 64 个二水平组合。若暂时按三组固定比例调节，则是另一种受限输入策略，应明确说明。

有效窗口完成后更新开度，在相邻窗口之间保持指令。控制设计需区分阀门动作时间、水流输运时间、结构热惯性、位移响应时滞及停机—返回—采样带来的反馈延迟，并处理不等间隔测量、交叉作用、开度范围、变化速率与弱可控方向。

区域贡献可帮助决定优先研究哪些区域；动态响应的符号、增益、时滞及交叉影响才是调阀规律的依据。是否采用 PID、MPC 或其他方法，应在响应模型和测量节拍明确后决定。
