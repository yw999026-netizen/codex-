## 当前最影响正文定稿的事项

1. G2 修复/更换与配套标定；否则必须改变目标点或研究范围。
2. 目标 P、新测点、Lp、Ls、轴方向及单位的实测记录。
3. 一份 API 原文件和同期旧温度系统记录，核对时间与字段。
4. 冷态与热态返回预试验，确定短窗口和分辨限。
5. 正式运动程序、八组合流量/水温、初始状态、基准/夜间策略及共同评价时段。
6. 独立重复及区组安排、主要指标和不确定性处理规则。

## 数据使用边界

仓库已有四种无水冷运动工况的旧三探头 Excel 和数据核查说明，包括待解释的末点计算差异及停机分界。它们可用于规划先导实验或独立历史分析；未核对目标点和测量链可比性前，不作为 API 八组合的替代数据。全文结果图、表、摘要与结论必须能回溯到原文件、处理版本和独立实验编号。
