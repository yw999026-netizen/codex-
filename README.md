## 当前研究状态（2026-10-26）

- 当前文章使用四份已有 R-test 无水冷记录，共 54 个有效窗口。用户确认运行时主轴持续旋转、回测时停转；各组主轴转速与停机分界待补。
- XYZ 联动末点 Y 原存值与矩阵复算差 30 μm，用户确认无人为加值。复算和差异记录另存，原始 Excel 保持不变。
- 后续 API 方案计划主轴全程停转，比较 X、Y、Z 单轴与 XYZ 联动；它不是本批历史 R-test 实验的加载条件。
- 分区统一为 **A＝床身、B＝立柱、C＝横梁**。运动激励影响与冷却抑制贡献分别分析。
- API 五点装置的下层 **G2（Y2）损坏**。正式任意高度等效刀尖三维测量应先恢复通道并核对标定；Lp＝0 的受限截面方案需验证几何及通道。
- API 原始文件格式、双温度源 MATLAB 合并接口尚待真实样例确认。仓库目前没有已验证的 API 实时采集或预测冷却闭环程序。
- 昼夜测量节拍、冷态基准、夜间恢复及控制适配见当前方案；具体数值仍是先导建议，不能当作已验证结论。

## 使用与维护

先通过各目录 README 确认入口和状态。旧程序的 MATLAB 版本、工具箱、串口、标定与机床条件并不统一，运行前按程序说明核对；文件名中的 Final、Fixed 不作为验证结论。

原始数据另存分析结果，模型与控制参数记录版本。新增实验按独立实验编号归档，记录真实时间、通道映射、冷态基准、运行和冷却状态。不要把缓存、凭证及临时工作文件提交到仓库。

本次整理检查文件完整性、文档链接、MATLAB 相邻依赖和重复项；未运行 MATLAB、API 软件、SolidWorks 或硬件实验。研究审计可在技能可用时优先参考 scientific-critical-thinking，结论仍应由测量及验证支持。
