## 维护规则

1. 根 README 只保留当前入口和关键状态；详细实验结果写入对应实验数据目录，研究讨论写入研究方案。
2. 程序注明用途、依赖和验证状态；历史版本放进对应历史分类，不通过文件名“最终版”认定可用。
3. 原始数据按实验编号归档，处理结果另存，记录参数、真实时间、通道和冷态基准。
4. 新代码尽量显式选择数据/标定路径；旧代码运行目录要求见 [程序说明](../程序/README.md)。避免整库递归加 MATLAB 路径造成同名函数冲突。
5. 不提交本地凭证、临时缓存和执行工作区。CAD 零件名与路径变更前，应先验证装配引用。

本次只执行仓库与文件完整性检查，未运行 MATLAB、API 软件或 SolidWorks，未执行硬件验证。仓库整理不能替代软件和装夹验证。
