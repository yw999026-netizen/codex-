# API 使用教程：Spindle Measurement System 与 SpindleModel

整理日期：2026-10-26。本文根据本目录已归档的厂家手册整理，供操作与离线分析参考；尚未在实际 Windows 软件、API 控制箱或机床上验证。

这里的 API 指 Automated Precision Inc.。下文将主轴测量软件称为 **Spindle Measurement System**，将主轴热变形建模软件称为 **SpindleModel**；建模说明书中的桌面快捷方式实际拼写为 `SpindleModle`。

## 1. 两个软件怎样配合

| 软件/模块 | 主要用途 | 操作结果 |
|---|---|---|
| Spindle Measurement System：动态分析 | 使用电容位移探头和转速索引信号测主轴动态误差 | 动态数据、径向/轴向误差分析图 |
| Spindle Measurement System：热分析 THERM500 | 同时记录电容位移探头与温度传感器数据 | 热测试原始数据、位移/温度/倾斜曲线 |
| SpindleModel | 读取主轴分析仪数据，选择模型点、筛选温度传感器并建模 | X、Y、Z 热位移模型、实测与模型对比、模型信息文件 |

热变形研究的主要顺序：**安装和标定文件确认 → 热测试采集 → 检查原始数据 → 打开 SpindleModel → 参数 → 过滤 → 建模 → 查看模型 → 保存 → 独立数据验证**。

标准热分析配置与 TMAC 配置的温度通道数不同：测量手册介绍标准热分析有 5 个外部温度传感器，启用 TMAC 时最多 20 个；建模说明书按 20 温度通道、5 位移通道介绍。应先确认现有设备配置及数据格式，不能把缺失通道自行填零后当作有效测量值。

## 2. 安装与首次连接

### 2.1 安装测量软件

依据：[安装指南](<软件说明书/SPN SW Installation manual.pdf>)，PDF 第 2—11 页；[测量手册](<软件说明书/SPN_MANUAL_41 _3_.pdf>)第 2 章。

1. 备份原安装介质、与控制箱序列号对应的标定文件及已有实验数据。测量手册明确要求软件标定参数与具体系统匹配。
2. 将随设备 USB 介质中的安装文件复制到电脑。运行 Spindle 安装程序；安装指南建议右键选择 `Run as administrator`。
3. 按安装向导选择 `Next`，完成后安装 USB 驱动。完成页有 `Install USB Driver` 按钮。
4. 若出现安装指南中的 `Installer 2821: InstallUSBDrv` 错误，按该指南走手动驱动安装流程：
   - 打开设备管理器，确认控制箱已正确连接并开启。
   - 查找 `Microchip Custom USB device`，或“其他设备”下的 `PICDEM FS USB Demo Board`。
   - 右键更新驱动，选择 `Browse my computer for driver software`。
   - 浏览到安装介质中的 `MCHPUSB Driver` 文件夹，完成安装，确认显示成功。
5. 将本机对应的 `.cnf` 标定文件复制到 Spindle Analyzer 软件目录。安装指南第 10 页明确要求此步骤，不能只完成主程序安装就开始正式测量。

安装指南适用于标注为 V3.7.6 或更新的版本；测量手册和建模手册分别介绍更早的 Windows 环境。报价资料还列有 WINNER 2.03。它们是不同资料中的版本信息，不能据此推定本机软件版本或 Windows 10/11 兼容性；现场应记录实际版本、系统及驱动状态。

### 2.2 连接与探头安装

依据：测量手册 §1.2、§2.4、§3.2.1、第 4—5 章。

1. **控制箱断电时接线**：将各编号电容探头接到对应接口，接温度传感器、USB 和电源。动态测试还需索引传感器；热分析模式不使用索引传感器。
2. 固定磁力座和夹具，按测量方向安装球或测试芯轴，记录探头与机床轴的对应关系。
3. 通电预热。一般注意事项写至少 10 分钟；动态测试流程写 15 分钟。初次操作可按动态流程预热 15 分钟，并检查读数稳定性。
4. 在软件 `Setup Screen` 中按画面编号调整探头，使读数对准界面的红色参考线，锁紧固定螺钉。
5. 按手册要求手动转动检查球/芯轴与探头无接触后，再进行转动测试。探头间隙按本机标定和软件指示调整，不把手册中的约 1 mm 显示起点当作通用工作间隙。

手册动态接线步骤出现“1、2、4”，后续调节及轴向分析又称第 3 探头，编号表述存在不一致。现场以实际设备标签、模块画面和配套标定为准，不能仅根据这一行文字改接通道。

## 3. Spindle Measurement System：先学离线查看

依据：测量手册 §3.1、§3.2.3、第 5 章。

1. 启动测量软件。启动选项中选 `Data Analysis`，可以不连接控制箱查看已有数据。
2. 选择与文件匹配的 `Spindle Type`，打开历史测试文件。
3. 热测试数据从 `View` 菜单切换以下图形：

| 菜单项 | 用途 |
|---|---|
| `Gauge & Thermal Sensor Error Plot` | 对照位移与温度变化 |
| `Gauge & Tilt Error Plot` | 对照位移与倾斜 |
| `Gauge Sensor Error Plot` | 检查位移探头曲线 |
| `Thermal Sensor Error Plot` | 检查温度曲线 |
| `Spindle Tilt Error Plot` | 查看主轴倾斜变化 |

4. 使用 `Data Table Text` 打开文本数据表。手册说明其为可供其他分析工具读取的 ASCII 文本；保留原始文件，分析副本另存。
5. 先核对文件头中的采样间隔、采样点数、主轴转速、探头间距、设备号和实验备注，再解释曲线。手册图 30 的示例文件扩展名为 `.dat`，这不表示所有版本只支持一种扩展名。

## 4. Spindle Measurement System：热变形采集

依据：测量手册第 5 章，重点为图 19—24、图 30。

### 4.1 建立热测试

1. 启动时选择 `Data Acquisition & Data Analysis`。
2. 在 `Spindle Type` 中选择 `Spindle Thermal Analyzer THERM500`。
3. 确认位移与温度实时读数有效、没有超量程或异常通道。热分析模式的转速由用户按机床设定输入，不能当作索引传感器实测值。
4. 打开 `SETUP`，设置下表参数，并用 `Save As` 指定本次数据路径。

| 字段 | 设置方法与单位 |
|---|---|
| `Sample Interval (sec)` | 采样间隔，单位 s，必须大于 0 |
| `Run Time (min)` | 图 21 界面标注为 min；正文要求数值 5—60，但将单位写成 seconds，见下方核对说明 |
| `Spindle Speed (rpm)` | 本次机床设定转速，单位 rpm |
| `S1-S4 Space (mm)` | 按实际探头布置确认间距；图示为 101.6 mm，不能直接用作任意设备的固定值 |
| `Machine ID`、`Operator`、`Comments` | 记录设备、操作者、工况、冷却状态等 |

**运行时间存在原文矛盾。** 英文手册印刷页 26 写 seconds，但印刷页 27（PDF 第 30 页）的图 21 明确写 `Run Time (min)`。操作时先核对本机字段单位，再用一次短测试和实际时长、点数确认。不能将输入 5 直接解释为采集 5 秒。图中 `Sample Interval = 10 s`、`Run Time = 5 min`、`1800 rpm` 仅为示例，不是本研究推荐工况。

### 4.2 采集并保存

1. 按既定实验工况设置主轴运行与冷却状态，记录实际启动/停机时刻。
2. 在采集界面点击 `S` 开始。观察位移和温度是否同时更新。
3. 等待软件报告采集结束、数据保存完成，再关闭或切换任务。
4. 用打开文件按钮重新打开刚保存的数据，检查温度与位移曲线、点数和文件头。
5. 保留原始文件及参数记录。若升温和停机冷却分成多个文件，记录每段实际时间和是否重新置零；后续拼接使用副本，保留分段依据。

本项目研究冷却影响时，应按实验方案记录并保持每组冷却条件。手册第 4 章“关闭主动主轴热控制”的要求属于其动态测试流程，不能直接套用为所有热测试都必须关闭水冷。

## 5. Spindle Measurement System：动态测试简明流程

依据：测量手册 §3.2.1—3.2.3、第 4 章。

1. 选择本机对应的动态测试模块，装好测球、位移探头及索引传感器。
2. 在 `Setup` 中，手册要求铣床选择 `Rotating Sensitive Direction`，车床选择 `Fixed Sensitive Direction`。
3. 用 `RPM` / `Speed Check` 检查转速。§3.2.1 要求转速稳定、变化小于 2%；第 4 章所写超过 10% 应检查索引安装，是故障排查提示，不应替代前面的稳定性要求。
4. 设置采集圈数。手册示例默认 20 圈，并介绍按最高转速的 10%、50%、100% 测试；这些是旧版手册的测试安排，具体转速应按设备允许范围和实验目的确定。
5. `Save As` 指定文件后进入采集界面，执行 `Start Data Acquisition`，等待转速检查、控制箱采样、数据传输及保存全部完成。
6. 打开数据查看 `asynchronous error`（异步误差）、`average radial error`（平均径向误差）及轴向结果，必要时用 `Data Table Text` 查看文本。

动态误差结果与热漂移曲线描述的现象不同，后续对比时应保留各自的测试模式、转速和采样设置。

## 6. SpindleModel：热变形建模

依据：[主轴热变形建模软件使用说明书](软件说明书/主轴热变形建模软件使用说明书.doc)，第二、三部分及图 7—16。

### 6.1 安装、打开数据

1. 使用配套安装程序 `setup.exe`，按向导安装。该说明书列明 Windows 2000/XP；现有资料未验证现代系统兼容性。
2. 从桌面 `SpindleModle` 快捷方式或开始菜单 `API Spindle modle software` 启动。
3. 菜单 `Language → Chinese` 切换中文。
4. 点击工具栏“打开”或“文件 → 打开”，选择 API 主轴分析仪采集的数据文件。若提示格式不正确，先检查文件版本、结构和通道配置，不修改原文件凑格式。
5. 查看温度与 5 路位移曲线，核对状态栏显示的采样次数和温度传感器数量。

### 6.2 先确认位移通道和坐标

建模说明书特别指出，旧版采集文件可能将 5 列标题错误标为 `X Y X2 Y2 Z`，正确物理对应如下：

| 物理探头 | 建模说明书中的名称 | 含义 |
|---|---|---|
| G1 | X2 | X 向一处位移 |
| G2 | Y2 | Y 向一处位移 |
| G3 | Z | Z 向位移，供计算 DZ |
| G4 | X1 | X 向另一处位移，也是模型点高度的参考位置 |
| G5 | Y1 | Y 向另一处位移 |

这一对应关系来自该版说明书，不表示任意版本的任意文件都应无条件重排。先查实际探头、软件版本和文件内容，保留原列名并另存映射记录。

若 G1/G4 在现场装在机床 Y 方向，说明书指出软件输出的 X、Y 解释会互换。实验记录中应写清“软件轴—实际机床轴”的对应关系。

### 6.3 设置模型点与筛选参数

点击工具栏“参数”。说明书主界面介绍将其列在“编辑”菜单，后文又写“设置”菜单；使用工具栏按钮可避免这处文字不一致。

**模型点高度 Lp：** 输入模型点相对 G4 的 Z 向高度，单位 mm，范围为 −500 至 +500 mm。说明书规定，G4 上方取正，下方取负。Lp 应由实际测量确定，不能直接采用刀具总长或未确认的程序坐标。

说明书给出的位移换算为：

```text
DX = X1 - Lp × (X2 - X1) / Ls
DY = Y1 - Lp × (Y2 - Y1) / Ls
DZ = Z
```

其中 Ls 是 G4 与 G1 的间距，说明书称其为固定值、无需用户输入。由于测量软件另有 `S1-S4 Space` 参数，应核对本机标定/配置与实际间距一致；现有手册未说明两个软件如何传递或固定这一数值。

Lp 和 Ls 必须使用同一长度单位。DX/DY/DZ 的单位随输入位移数据而定，先从软件与标定确认，导入 MATLAB 时再明确换算，不能仅凭小数大小断定为 mm 或 μm。

**温度—位移线性相关系数：** 说明书默认 0.800，建议在 0.750—0.950 调整，用于温度传感器筛选。它是软件筛选参数，不是模型精度或置信度。T1 在该软件中固定作为环境温度传感器，筛选后仍参与建模，因此采集时需核对 T1 的实际布置。

### 6.4 过滤、建模、查看与保存

1. 参数确认后点击“过滤”，在确认框选择“是”。此处“过滤”指温度传感器筛选，不能当作对曲线做平滑去噪。
2. 在状态栏查看筛选后参与建模的温度传感器数量。“建模”按钮在过滤完成后启用。
3. 点击“建模”，等待完成。软件分别建立 X、Y、Z 模型，并显示实测与模型曲线。
4. 依次查看 X、Y、Z 对比图。说明书图 10 将实测曲线标为黄色、模型曲线标为红色；若现场改过颜色，应以图例为准。
5. 查看图右侧正、负方向最大偏差和对应点位置。手册未明确偏差的相减顺序，记录时保留软件标注；如自行计算，应注明残差定义。
6. 点击“查看模型”，记录入选温度传感器编号及 X/Y/Z 方程，点击该窗口的“保存”保存模型信息。
7. 若调整 Lp 或相关系数，重新执行“过滤 → 建模 → 查看模型”，将该次参数和模型另存，避免只保留最后一张拟合图。

## 7. 用于本仓库实验时怎样判断结果

以下为结合本项目提出的分析建议，不是厂家菜单功能或已完成的验证。

- **区分拟合与验证。** 软件在打开的数据上建立并显示模型，对这份数据拟合良好不等于其他工况预测准确。使用独立实验，或按完整时间段划分训练与验证，避免随机打散相邻采样点造成评价偏乐观。
- **保留升温与冷却阶段。** 分别记录运动、停机和冷却条件，不把停机后的温度下降直接当作热误差已经归零。
- **比较一致的模型点。** 不同 Lp、探头朝向、零点和间距会改变位移解释。使用同一物理目标点及明确坐标映射后再比较模型。
- **本仓库的 18 温度/3 探头 Excel 不等同于 API 的 20 温度/5 位移原始文件。** 现有资料没有说明 SpindleModel 能直接导入这些 Excel。若需关联分析，应先验证格式、标定矩阵、单位与模型点几何关系，不能补两列零就套用上述五探头公式。
- **模型保存不等于补偿上线。** 建模说明书说明了模型信息保存，没有给出当前机床控制器的补偿接入步骤。应先离线核查预测与残差，再另行确认控制器接口和坐标符号。

每次建模建议一并保存：原始数据、软件版本、采样间隔、工况时间记录、冷却状态、通道映射、单位、Lp、Ls 来源、相关系数、入选传感器、三轴模型方程以及验证结果。

## 8. 常见问题速查

| 现象 | 优先检查 |
|---|---|
| 主程序可开，但不能采集 | 是否选了采集模式；控制箱、USB 驱动、`.cnf` 标定文件是否正确 |
| `Out of Range` 或读数异常 | 探头间隙、安装、通道和本机量程；先回到 Setup 检查 |
| 动态测试 RPM 不稳定 | 索引传感器安装、信号及实际转速稳定性 |
| 热测试时长与预期不符 | 本机 `Run Time` 单位及采样间隔；对照实际时长和保存点数 |
| SpindleModel 提示格式不对 | 是否为该软件支持的 API 原始数据、文件版本及完整通道结构 |
| “建模”按钮不可用 | 是否已成功打开数据并完成“过滤” |
| 建模曲线方向或幅值异常 | G1—G5 映射、X/Y 朝向、Lp 正负、Ls、位移单位和零点 |
| 某次拟合好，另一次偏差大 | 环境、工况、冷却、目标点及训练范围是否一致；用独立数据量化偏差 |
