# MATLAB定时采集时序不准问题修复方案

## 问题诊断

你的程序设置2秒采样周期,但实际并不准确。根据代码分析,主要原因:

### 1. Timer配置问题
```matlab
% 原代码(第1209-1221行)
acqTimer = timer( ...
    'ExecutionMode', 'fixedRate', ...      % ❌ 问题1
    'Period', sampleIntervalSec, ...
    'StartDelay', sampleIntervalSec, ...
    'BusyMode', 'drop', ...                % ❌ 问题2
    'TimerFcn', @acquisitionTick, ...
    'ErrorFcn', @timerErrorCallback);
```

**问题分析:**
- `fixedRate`: 从**上次触发时间**开始计算下一次触发,会累积误差
- `BusyMode = 'drop'`: 如果一次采集超过2秒,会**跳过**下一次触发

### 2. 通信耗时累积
你需要读取:
- 3次温度读取(地址1, 2, 3,分别8, 8, 2路)
- 3次电涡流读取(地址5, 6, 7)
- **共计6次Modbus通信**

假设每次通信耗时0.2-0.3秒,总计1.2-1.8秒,接近2秒周期!

### 3. GUI更新耗时
```matlab
updateCurrentDisplay();  % 更新表格
updatePlots();           # 更新3个图表
drawnow limitrate;       % 强制刷新
```

## 解决方案

### 方案1: 修改Timer配置(推荐)

```matlab
% 修复后的配置
acqTimer = timer( ...
    'ExecutionMode', 'fixedSpacing', ...   % ✅ 从执行结束后开始计时
    'Period', sampleIntervalSec, ...
    'StartDelay', sampleIntervalSec, ...
    'BusyMode', 'queue', ...               % ✅ 不丢弃触发
    'TimerFcn', @acquisitionTick, ...
    'ErrorFcn', @timerErrorCallback);
```

**改进说明:**
- `fixedSpacing`: 从**上次执行完成**后开始计时,补偿执行时间
- `BusyMode = 'queue'`: 即使执行超时也排队执行,不会跳过

**注意:** 这种方式实际间隔 = 2秒 + 执行时间

### 方案2: 手动时间补偿(最精确)

替换原来的timer方式,改用带时间补偿的循环:

```matlab
function acquisitionTick(~,~)
    persistent nextScheduledTime;
    
    if isempty(nextScheduledTime)
        nextScheduledTime = tic + sampleIntervalSec;
    end
    
    if ~collecting
        return;
    end
    
    try
        %% 读取数据
        tic_read = tic;
        [tempVals, probeVals] = readAllSensors();
        readTime = toc(tic_read);
        
        % 检查读取是否超时
        if readTime > 1.5
            fprintf('⚠️ 警告: 本次读取耗时%.2f秒,接近周期限制\n', readTime);
        end
        
        %% 更新数据
        sampleIndex = sampleIndex + 1;
        tNow = sampleIndex * sampleIntervalSec;  % 理论时间
        
        full_time(end+1) = tNow;
        full_temp(:,end+1) = tempVals;
        full_probe(:,end+1) = probeVals;
        
        lastTemp = tempVals;
        lastProbe = probeVals;
        
        %% 测量窗口处理
        handleMeasurementWindow(tempVals, probeVals, tNow);
        
        %% GUI更新(降低频率)
        if mod(sampleIndex, 2) == 0  % 每4秒更新一次GUI
            updateCurrentDisplay();
            updatePlots();
        end
        
        %% 命令行输出
        fprintf(...
            ['时间=%6d s | ' ...
             'T1=%5.1f T2=%5.1f T3=%5.1f | ' ...
             'P1=%7.2f P2=%7.2f P3=%7.2f μm | ' ...
             '读取耗时=%.3fs\n'], ...
            tNow, ...
            tempVals(1), tempVals(2), tempVals(3), ...
            probeVals(1), probeVals(2), probeVals(3), ...
            readTime);
        
        drawnow limitrate;
        
        %% 计算下次触发的精确时间
        nextScheduledTime = nextScheduledTime + sampleIntervalSec;
        
    catch ME
        fprintf(...
            '⚠️ 第%d个采样周期读取失败：%s\n', ...
            sampleIndex+1, ME.message);
    end
end
```

### Step 2: 在 acquisitionTick 函数中添加耗时监控

在原代码第1241行的函数开头添加:

```matlab
function acquisitionTick(~,~)
    persistent readTimeHistory;
    
    if isempty(readTimeHistory)
        readTimeHistory = [];
    end
    
    if ~collecting
        return;
    end
    
    tic_total = tic;  % 记录总耗时
    
    try
        %% 读取数据
        tic_read = tic;
        [tempVals,probeVals] = readAllSensors();
        readTime = toc(tic_read);
        
        % 记录读取耗时
        readTimeHistory(end+1) = readTime;
        if length(readTimeHistory) > 100
            readTimeHistory(1) = [];  % 只保留最近100次
        end
        
        % 超时警告
        if readTime > 1.5
            fprintf('⚠️ 通信超时: %.2f秒\n', readTime);
        end
        
        %% ... 原有的数据处理代码 ...
        
        totalTime = toc(tic_total);
        
        % 每10次采样输出一次性能统计
        if mod(sampleIndex, 10) == 0
            avgReadTime = mean(readTimeHistory);
            maxReadTime = max(readTimeHistory);
            fprintf(...
                '📊 性能统计: 平均读取%.3fs, 最大%.3fs, 本次总耗时%.3fs\n', ...
                avgReadTime, maxReadTime, totalTime);
        end
        
    catch ME
        % ... 错误处理 ...
    end
end
```
