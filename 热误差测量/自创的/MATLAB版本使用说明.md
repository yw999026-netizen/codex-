## 🆕 新增功能

### 1. **实时PID控制**
- 每2秒采集后自动计算PID输出
- 根据位移偏差自动调节球阀开度
- 可在GUI上启动/停止控制

### 2. **可调节控制目标**
- 控制目标可在GUI实时修改
- 默认目标为0μm（抑制热误差）

### 3. **增强的Modbus通讯**
- 自动重试机制（默认3次）
- 连续失败自动切换模拟模式
- 掉帧检测

### 4. **球阀控制面板**
- 显示当前球阀开度
- 显示PID参数
- 一键启停控制

### 5. **球阀控制曲线**
- 实时显示控制指令 vs 实际反馈
- 安全开度范围标识

## 🚀 快速开始

### 步骤1: 硬件连接

1. 连接18路温度传感器（Modbus地址 1、2、3）
2. 连接3个电涡流传感器（Modbus地址 5、6、7）
3. 连接电动球阀（默认地址10，需确认）
4. 所有设备通过RS485连接到同一个COM口

### 步骤2: 配置参数

修改程序开头的配置参数（见上一节）

### 步骤3: 运行程序

```matlab
>> ThermalErrorControl_WithPID_V1
```

### 步骤4: 操作流程

#### 冷机阶段
1. 点击"**开始连续采集**"
2. 机床停在固定检测位
3. 点击"**设置冷态零点**"
   - 系统会等待5秒稳定
   - 自动采集10个点取平均
   - 建立冷态基准

#### 实验阶段
1. 机床开始运行（加工/空运行）
2. 定期返回固定检测位
3. 点击"**记录热误差样本**"（可选）
   - 记录建模样本

#### 控制阶段
1. 在**PID控制面板**中点击"**启动自动控制**"
2. 系统会根据位移自动调节球阀
3. 可随时修改控制目标

#### 结束
1. 点击"**停止并保存**"
2. 自动生成Excel文件

## 🔧 PID参数整定指南

### 初始参数推荐

```matlab
Kp = 0.3  ~ 0.8    % 从保守值开始
Ki = 0.005 ~ 0.02
Kd = 0.05 ~ 0.2
```

### 整定步骤

#### 第1步：仅P控制
1. 设置 `Ki = 0`, `Kd = 0`
2. 从小的Kp开始（如0.2）
3. 逐步增大Kp
4. 观察响应速度
   - 如果响应太慢 → 增大Kp
   - 如果出现振荡 → 减小Kp

#### 第2步：加入I控制
1. 固定上一步的Kp
2. 加入小的Ki（如0.01）
3. 观察稳态误差
   - 如果仍有稳态误差 → 增大Ki
   - 如果开始振荡 → 减小Ki

#### 第3步：加入D控制
1. 固定Kp和Ki
2. 加入小的Kd（如0.1）
3. 观察超调和振荡
   - 如果超调大 → 增大Kd
   - 如果响应变慢 → 减小Kd

### 调试技巧

1. **先开环测试**
   - 不启动控制，手动设定不同球阀开度
   - 观察位移变化规律
   - 估算系统响应时间

2. **从保守参数开始**
   - 宁可慢一点，也不要振荡
   - 球阀响应通常较慢（5-30秒）

3. **利用死区**
   - 默认±2μm死区避免频繁调节
   - 如果精度要求高，可减小死区

4. **积分限幅很重要**
   - 防止积分饱和
   - 建议设为50-100

5. **记录每次参数**
   - 在Excel中查看控制效果
   - 对比不同参数的响应曲线

### 常见问题

| 现象 | 原因 | 解决方案 |
|------|------|---------|
| 位移持续振荡 | Kp或Kd过大 | 减小Kp和Kd |
| 响应太慢 | Kp太小 | 增大Kp |
| 有稳态误差 | Ki太小或为0 | 增大Ki |
| 超调很大 | Kd太小 | 增大Kd |
| 球阀频繁抖动 | 死区太小 | 增大deadband |

## ⚠️ 注意事项

### 安全相关

1. **首次运行建议离线模式**
   - 设置 `forceOfflineMode = true`
   - 验证程序逻辑正确再连接真实设备

2. **球阀开度限制**
   - 硬限制：10% ~ 90%
   - 防止球阀完全关闭或全开

3. **紧急停止**
   - 位移超过±100μm自动停止控制
   - 球阀设为安全位置

4. **人工监控**
   - 初期建议人工监控控制过程
   - 发现异常立即点击"停止自动控制"

### 控制相关

1. **先设置冷态零点**
   - 控制算法依赖冷态零点
   - 否则控制目标不正确

2. **控制目标**
   - 0μm表示抑制热误差
   - 也可设置为非零值（补偿其他因素）

3. **控制输入**
   - 默认使用探头1的位移
   - 可修改为三探头平均（代码第行）

4. **采样周期固定**
   - 2秒一个采样点
   - 不建议修改（与热误差变化速度匹配）

### 硬件相关

1. **COM口独占**
   - 确保没有其他程序占用串口
   - 运行前关闭串口调试助手

2. **球阀响应时间**
   - 球阀从一个开度到另一个开度需要时间
   - 通常5-30秒
   - 影响控制效果

3. **Modbus地址冲突**
   - 确保所有设备地址不重复
   - 温度：1、2、3
   - 电涡流：5、6、7
   - 球阀：10（默认）

## 🐛 故障排查

### 问题1: 提示"Modbus连接失败"

**原因**:
- COM口号错误
- 串口被占用
- 波特率不匹配

**解决**:
```matlab
% 查看可用串口
instrfind

% 删除所有串口对象
delete(instrfindall)

% 修改COM口和波特率
comPort = 'COM5';  % 改为实际端口
baudRate = 19200;  % 改为实际波特率
```

### 问题2: 读取球阀失败

**原因**:
- 球阀Modbus地址错误
- 寄存器地址错误
- 球阀未上电或故障

**解决**:
1. 查阅球阀手册确认：
   - Modbus从机地址
   - 位置设定寄存器
   - 位置反馈寄存器
   - 数据格式（直接百分比还是需要缩放）

2. 使用Modbus调试工具测试

3. 暂时注释球阀相关代码测试采集

### 问题3: PID控制效果差

**症状**: 位移持续振荡

**解决**:
- 减小Kp（减半尝试）
- 减小Kd
- 增大死区到±5μm

**症状**: 控制太慢无法抑制热误差

**解决**:
- 增大Kp（加倍尝试）
- 检查球阀响应是否正常
- 确认球阀开度变化确实影响温度

### 问题4: 程序卡顿或无响应

**原因**:
- 18条温度曲线绘图太频繁
- 定时器积压过多

**解决**:
```matlab
% 减少显示点数
maxDisplayPoints = 5000;  % 默认10000

% 减少曲线数量（注释部分温度）
% 或使用子采样绘图
```

### 问题5: 数据保存失败

**原因**:
- Excel文件被占用
- 磁盘空间不足

**解决**:
- 关闭同名Excel文件
- 修改保存路径到有足够空间的盘

## 💡 高级功能

### 1. 修改控制输入

默认使用探头1，可修改为三探头平均：

```matlab
% 在acquisitionTick函数中找到：
controlInput = probeVals(1);  % 原代码

% 修改为：
controlInput = mean(probeVals);  % 三探头平均
```

### 2. 添加前馈控制

基于温度预测位移变化：

```matlab
% 在PID计算前添加：
tempRise = mean(lastTemp) - mean(zeroTemp);
feedforward = 0.5 * tempRise;  % 系数需调整

% 控制输出：
valveCommand = pid.compute(controlInput) + feedforward;
```

### 3. 自适应PID

根据误差大小动态调整参数：

```matlab
error = abs(pid.setpoint - controlInput);

if error > 50
    % 大误差：快速响应
    pid.Kp = 1.0;
    pid.Ki = 0.005;
elseif error > 10
    % 中等误差：平衡
    pid.Kp = 0.5;
    pid.Ki = 0.01;
else
    % 小误差：精细控制
    pid.Kp = 0.3;
    pid.Ki = 0.02;
end
```
