# API 测量系统实验步骤：主轴停转、XYZ 运行与定点热误差回测

更新日期：2026-10-26。状态：现场预试验与正式实验操作方案，尚未完成 API 软件、机床或硬件验证。

本轮采用 API 配套测量系统，主轴全程保持停止，由 X、Y、Z 单轴或联动运行产生热激励；周期性返回同一测量位姿，静止读取相对冷态的热位移。测量软件为 **Spindle Measurement System（Spincheck.exe）**，后续建模软件为 **SpindleModel（SpindleModel.exe）**。

## 1. 实验目标与本轮测量配置

目标是获得固定模型点相对工作台侧测量基准的带符号 XYZ 热位移，以及对应温度、运动和冷却记录。该结果反映测量链的综合变化，可能包含进给系统、机床结构、夹具漂移与重复定位影响，不能全部解释为主轴自身热伸长，也不能直接推广为全行程误差。

| 项目 | 本轮安排 |
|---|---|
| 主轴 | 全程停止；保持并记录角向位置，避免回测时发生未记录的重新定向 |
| 热激励 | 分别安排 X、Y、Z 单轴或 XYZ 联动；速度、行程和加减速按现场方案填写 |
| 测量装置 | API 控制箱、配套电容探头、测试芯轴及温度传感器 |
| 测量模式 | Spindle Measurement System 的 `Spindle Thermal Analyzer THERM500`；以本机实际模块为准 |
| 测量位置 | 固定机床坐标、固定装夹、固定最终接近方向和模型点 |
| 基准 | 每轮独立实验建立一次冷态基准，整轮沿用 |
| 温度通道 | 记录实际安装数量及测点；标准热分析与 TMAC 配置可能不同 |
| 冷却 | 先完成测量预试验，再按无水冷基线及既定冷却工况开展实验；记录各支路实际状态 |
| 后处理 | 提取有效回测窗口；确认文件兼容后使用 SpindleModel，必要时另行在 MATLAB 中分析 |

旧的 18 路温度、3 个电涡流探头及其标定矩阵属于原测量链，不能直接作为 API 五探头的标定或接口配置。历史数据保留为历史记录；两套系统的结果比较前，应核对目标点、坐标、单位、冷态基准及工况。

## 3. 安装、接线与装夹

1. 备份原安装介质及本机标定文件，确认 Spindle Measurement System、USB 驱动已安装，匹配本机的 `.cnf` 文件位于软件安装目录。
2. 控制箱断电时连接编号对应的位移探头、温度传感器、USB 和电源。检查探头接口与软件显示的对应关系。
3. 将测量夹具固定在工作台侧，测试芯轴固定在主轴侧，保存装夹照片和测点位置记录。
4. 规划芯轴退出、XYZ 运行、重新进入夹具的路线。五探头装置的间隙较小，先确认整条路径无干涉，不能直接套用旧三探头装置的运动路线。
5. 通电预热并观察读数稳定性。手册一般注意事项要求至少 10 min，动态流程采用 15 min；本轮可先按 15 min 做预试验，实际稳定性另行记录。
6. 启动软件，在设置画面按本机标定调整探头间隙和参考位置，确认全部所需通道有效。手册截图中的间距、量程及原位读数不作为本机通用设定。

## 4. 预试验 A：主轴停转时能否正常采集

本阶段 XYZ 与主轴均静止，先确认数据链路。

1. 打开 **Spindle Measurement System**。
2. 启动窗口选择 **`Data Acquisition & Data Analysis`**。
3. 在 **`Spindle Type`** 中选择 **`Spindle Thermal Analyzer THERM500`**。
4. 检查位移与温度实时读数，打开 **`SETUP`**。
5. 按下表设置，点击 **`Save As`** 指定预试验文件；在采集界面点击 **`S`** 开始。
6. 等待结束和保存完成，重新打开文件，用 **`Data Table Text`** 核对数据。

| 字段 | 预试验设置与核对方法 |
|---|---|
| `Sample Interval (sec)` | 若本机允许，先试 2 s；检查保存文件是否与实际采样一致 |
| `Run Time (min)` | 若界面与手册一致，先试 5 min；记录实际开始与结束时刻 |
| `Spindle Speed (rpm)` | 按实际填 0；确认是否接受并能采集，不用虚构的非零值绕过限制 |
| `S1-S4 Space (mm)` | 按本机配置及实际间距核对，不照抄图中的 101.6 |
| `Machine ID`、`Operator`、`Comments` | 填写设备与操作者，注明“主轴停止，XYZ 静止，功能检查” |

手册第 5 章明确热分析模式不使用索引传感器，但未明确保证任意版本允许输入 0 rpm。若本机拒绝或要求主轴旋转，保存提示及软件版本，先解决该项后再执行正式采集。

**时间单位核对：** 手册印刷页 26 的正文写 seconds，图 21（印刷页 27、PDF 第 30 页）却写 `Run Time (min)`。以本机字段和实际计时共同核对；手册中的 5—60 范围也需本机确认。

完成时留下：原始文件、软件版本、参数记录、实际时长、各通道静止波动、文件能否重开的结论。该阶段同时确认显示值/文件值是否自动置零及其参考点，不能只凭图形看起来正常就判断基准保留。

## 5. 预试验 B：退出、返回与基准保持

1. 保持热状态尽量稳定，在测点取得初始稳定窗口。
2. 按已确认的退出路线离开探头有效区域，记录退出时间及软件行为。
3. 执行一段短的返回验证路线，从约定方向接近同一机床坐标；主轴保持停止和相同角向位置。
4. 分别记录返回开始、到位、稳定窗口开始及结束时间，保存窗口原始读数。
5. 初步重复 5—10 次，比较窗口均值的散布、窗口内波动及温度变化。这只是预试验建议次数，不能替代正式实验重复设计。
6. 观察是否超量程终止采集、恢复后能否继续保存、跨文件是否重新置零。需要分文件时，使用可追溯的同一参考读数或已验证的零点转换，不能将各文件的相对零点直接拼接。

等待时间和窗口可先以 **到位后等待 5 s、按 2 s 采 10 个有效点** 做探索；这些是沿用旧方案的试用值，不是 API 厂家推荐参数。10 点首末理论间隔为 18 s，实际时间以记录为准。根据静止和重复返回结果确定最终参数，并在代表性热态再次检查。

### 采集方式的选择

| 本机验证结果 | 操作方式 |
|---|---|
| 离位仍能记录，返回后恢复正常，基准保持 | 连续采集并另存事件时间；后处理仅提取有效回测窗口 |
| 每次需重新开始采集，但原始读数或零点关系可追溯 | 分段保存，记录每段时刻及零点关系，仍相对整轮冷态基准计算 |
| 重新采集会重置参考且无法恢复原基准 | 当前流程不足以形成可靠热漂移序列；先确认原始值导出或厂家支持的基准保持方法 |

若本机每个文件最长仅允许 60 min，应提前规划分段与衔接，记录切换产生的缺口和零点关系，不将缺口压缩掉。界面最短时长若为 5 min，不代表每次回测都应停留 5 min；回测只取经验证的短稳定窗口。若软件无法实现短窗口记录或连续采集，需先解决采集方式，避免长时间停留改变预期热历史。

正式热实验前，应将返回散布与预计热漂移、最小关心的冷却改善量进行比较，记录可分辨范围。窗口内平均只能降低部分随机波动，不能消除系统性的返回偏差或夹具漂移。

## 6. 正式实验：固定运行—回测循环

### 6.1 建立本轮冷态基准

1. 确认初始热状态满足已记录的接受条件；登记环境、关键温度及冷却状态。
2. 按统一方向进入测量位姿，检查主轴角向位置、机床坐标和有效间隙。
3. 采用预试验确定的稳定等待和采样窗口，保存 G1—G5、温度及实际时间。
4. 保存本轮冷态平均值、波动、标定信息和参数。整轮保持同一基准；需要重新归零时，结束当前实验编号并重新建立基准。

### 6.2 重复以下循环

| 顺序 | 现场操作 | 必须保存的记录 |
|---|---|---|
| 1 退出 | 按确认路线退出测量夹具 | 退出时刻，测量状态转为无效 |
| 2 运行 | 主轴保持停止，XYZ 按本组工况运行 | 起止时刻、速度/行程、往复次数、冷却状态 |
| 3 返回 | 达到预定节拍后返回，保持相同最终接近方向 | 运行暂停、开始返回、到位时刻 |
| 4 稳定 | 等待预定时间并检查实际稳定性 | 是否静止、通道是否有效、异常原因 |
| 5 测量 | 采集完整稳定窗口，温度按同一时间窗口关联 | 原始点、均值、波动、点数、窗口时间 |
| 6 保存 | 相对本轮冷态基准计算 XYZ 热位移，记录有效性 | 热位移、单位、坐标映射、对应原文件行/时间 |
| 7 继续 | 按原工况继续运行 | 恢复运行时间；若改变冷却或工况，记录具体动作 |

芯轴离位、运动、返回、等待和超量程时的探头记录均不能作为有效热位移。保存原始记录及无效原因，不能把无效值填成 0；软件未确认具备自动到位识别功能时，由操作者另记事件时间。

尽量固定每次回测的返回路线和停留时长，并记录偏离。回测会中断进给运行，所得结果对应本套运行—回测循环的热历史，不能直接解释为无中断加工过程中的连续误差。

### 6.3 停机冷却与结束

1. 达到预定运行终点后，记录最后停止进给的准确时刻和冷却设备状态。
2. 按预定规则继续定点观测，明确哪些样本属于停机冷却阶段；保持原冷态基准。
3. 采用已确定的停机观测方式，例如保持测量位姿静止采集，并与运行阶段的回测模式区分记录。
4. 达到预定观测时长或结束条件后，等待文件保存完成，重新打开核查，备份原始文件和事件记录。

## 7. 通道换算与结果解释

建模手册定义的物理通道关系为：G1＝X2、G2＝Y2、G3＝Z、G4＝X1、G5＝Y1。旧版数据文件可能错标为 `X Y X2 Y2 Z`，需根据实际版本与装置核对，不能仅凭表头重排。

模型点的换算为：

```text
DX = X1 - Lp × (X2 - X1) / Ls
DY = Y1 - Lp × (Y2 - Y1) / Ls
DZ = Z

本次热位移 ΔD = 本次有效窗口的 D 平均值 − 本轮冷态窗口的 D 平均值
```

Lp 为模型点相对 G4 的高度，单位 mm，手册规定上方为正、下方为负，输入范围为 ±500 mm。Ls 为 G4 与 G1 的间距；建模说明书称其为内部固定值，而测量软件提供间距字段，两者的实际配置关系需要确认。

Lp 与 Ls 使用同一长度单位；位移结果沿用输入位移单位。先确认 API 文件单位，再按需要统一转换为 μm。若软件已经输出相对冷态的热位移，应核对其基准后使用，避免未经核对再重复处理。实际 X/Y 安装方向、探头正负方向和目标点均应记录；不要套用旧三探头转换矩阵。

## 8. 数据文件与现场记录

建议每轮使用独立文件夹，原始文件保留软件原格式和文件名。下列目录是归档建议，不是软件自动生成内容：

```text
实验编号/
  raw/                 API 原始测量文件
  setup/               软件参数、装夹照片、通道与标定信息
  events.csv           运行、返回、测量、停机和冷却动作记录
  windows.csv          每次有效窗口和失败窗口的汇总
  processed/           单位换算、时间对齐与热位移结果
  models/              模型参数、方程和独立验证结果
```

最低记录要求：

| 记录 | 内容 |
|---|---|
| 事件 | 实验编号、实际时间、事件类型、工况、操作者备注 |
| 文件衔接 | 文件名、开始/结束时刻、原时间轴含义、零点关系、缺口 |
| 测量窗口 | 样本号、冷态/运行回测/停机冷却、到位/起止/代表时间、原文件位置 |
| 测量值 | G1—G5 原始点及均值、温度、XYZ 热位移、单位、坐标映射 |
| 质量 | 有效点数、波动、有效性与失败原因、标定/参数版本 |
| 冷却 | 支路设定及实际可读状态、流量/温度、启停及调整时刻 |

API 文件时间轴与另记事件应使用可核对的时间基准。若软件只有采样序号，应记录文件开始时刻、间隔及暂停/缺口；由序号推算的时间要注明推算依据，不能冒充实际逐点时间。

## 9. SpindleModel 的使用步骤与输入条件

**先验证兼容性，再正式建模。** 软件说明书介绍的是 API 原始数据读取，没有提供任意 Excel 导入、无效回测时段剔除或间歇文件重建方法。标准热分析可能仅配 5 路温度，建模手册按 20 路介绍，现场应确认实际文件是否被正确识别；缺失通道不补零冒充实测。

1. 先用预试验文件打开 SpindleModel，核对采样点数、温度和五路位移曲线，验证文件及通道识别。
2. 正式建模输入只能包含有对应关系的有效温度与位移样本。确认当前版本能否通过受支持的方式选取/导入这些样本；原始连续文件里的离位超量程数据不能直接参与建模。
3. 打开软件，必要时执行 `Language → Chinese`，点击“打开”载入已确认兼容的数据。
4. 点击“参数”，设置实际 Lp 和相关系数。相关系数可先用手册默认 0.800，记录每次调整；T1 按该软件约定作为环境温度。
5. 点击“过滤”筛选温度传感器，再点击“建模”。这里的“过滤”不等于剔除离位数据或曲线去噪。
6. 分别查看 X/Y/Z 实测与模型曲线，记录正负最大偏差、点位置与入选通道。
7. 点击“查看模型 → 保存”，同时保存输入文件、参数、模型点和坐标/单位说明。
8. 使用独立实验验证模型。说明书未确认独立文件验证的一键功能；必要时导出方程，在 MATLAB 等工具中用独立数据计算预测与残差，固定残差定义。

若当前版本无法正确接收间歇有效样本，先完成可靠测量与归档，采用另外编写并验证的 MATLAB 后处理/建模流程，或取得厂家支持的格式转换方法。不要仅改文件扩展名、删几行或伪造等间隔时间后直接输入软件。模型方程保存也不表示已接入机床补偿。

## 10. 本轮实施顺序与待验证事项

建议先后完成：

1. 静止采集与原文件重开检查。
2. 短距离退出—返回重复性、离位处理和基准保持检查。
3. 一组单轴运行热实验，检验整条数据链和停机冷却记录。
4. 按同一测量流程开展 X、Y、Z、XYZ 工况；各组恢复到可比的初始条件，记录差异。
5. 冻结回测和评价规则后开展冷却对照，再做模型与独立验证。

正式实施前逐项填写预试验结果：

- [ ] 热分析模式允许主轴停转采集，0 rpm 的实际行为已记录。
- [ ] 实际采样间隔、运行时间单位、文件时长限制已核对。
- [ ] 通道、单位、标定、模型点及 Ls 配置已核对。
- [ ] 退出与返回路线适合 API 夹具，固定同向接近与主轴角向位置。
- [ ] 离位恢复、文件分段、零点保持和保存完整性已验证。
- [ ] 窗口等待及点数由静止/返回试验确定，重复性与关注的误差量级相适应。
- [ ] 温度与窗口时间对应清楚，冷却及运行状态有记录。
- [ ] SpindleModel 输入兼容性及有效样本处理方式已确认，或明确采用其他后处理方式。
