## 复现方法

依赖 Python、numpy、openpyxl、matplotlib。在仓库根目录运行：

```bash
python 论文写作—无api/分析工具/analyze_rtest.py
```

脚本相对自身定位仓库，只读原 Excel，输出到本目录，重新运行会覆盖本目录的派生结果。每文件采用自身 C 与冷态零点，逐一核对：探头均值减冷态＝所存差值；窗口包含 5 点；探头均值和矩阵换算后三向样本标准差可由连续窗口复现。读写前后验证源文件哈希一致。

保存值与复算差异阈值为 1e-6 μm，是数值一致性检查容差，不是仪器精度。XYZ 样本 7 Y 差异 30 μm，用户确认无人为加值；派生分析采用保存矩阵复算口径，原因待追溯，不覆盖源文件。

全部样本 RMS 按已存不等间隔窗口等权计算，只描述当前样本分布，不是连续时间或共同升温阶段的 RMS。观测最大值不是未观测段峰值。对照研究缺独立重复、工况与环境可比性、停机分界等证据，不能据数值排序作因果归因。
