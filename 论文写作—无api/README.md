## 当前文章能支持的范围

四份现有记录全部无分区水冷，每工况当前只纳入一份记录，分别含 14/16/17/7 个窗口。首先写运动工况下的三维热漂移、窗口测量有效性、数据一致性和末段响应。由于主轴共同参与发热、环境和时长不同且缺少独立重复，不能从这四组求结构产热权重、宣称等条件工况排序或报告水冷抑制率。

XYZ 末点 Y 与其文件标定复算相差 30 μm。用户否认人为加值后，派生分析采用可复现的矩阵复算口径，原 Excel 和原值始终保留；原因仍待追溯，不能将数值一致性视为标定绝对精度验证。

## 修订顺序

1. 补齐四组主轴转速、进给速度/行程、回测规则、测点及装夹照片。
2. 补齐停止进给时间或首个冷却样本，追溯 XYZ 原值差异原因。

4. 补标定、复位与温漂证据，并判断是否增加独立重复。
5. 补文献和结果图表，最后压缩摘要、结论并按期刊格式整理。
