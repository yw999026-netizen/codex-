# 无 API 论文：参考文献与首轮仿照实验方案

日期：2026-10-27。状态：实验设计稿，尚未执行。使用现有三电涡流探头、标准球及温度采集系统，与[当前论文初稿 v0.3](中文期刊论文初稿.md)配套。

## 1. 当前决定与论文问题

继续沿“固定测点三维热漂移”主线开展论文写作。先做一轮 X 轴试验，确认测量链、运行/恢复分界及数据保存均可靠，再扩展工况。已有四记录继续保留为历史探索数据，新试验独立编号，不将新设定写回旧记录。

建议研究问题：在规定主轴背景及进给循环下，同一测点的 ΔX、ΔY、ΔZ 如何变化？停止加载后，各方向是否同步接近初始位置？这种响应能否在独立试验中复现？

本文使用球心相对于探头架的三维相对漂移。单位置三路观测不足以独立分解平移、倾斜、球径变化或结构区域热贡献；“首次使用 R-test”不作为创新表述。现有初稿中的计算差异核查作为数据质量说明，不单独当作主要科学贡献。

### 文献方法怎样转化为你的实验

| 文献启发 | 本项目采用的做法 | 范围 |
|---|---|---|
| 分开组织加载与恢复 | 明确记录加载起止、每次回测暂停及恢复起点 | 不从温度拐点猜停机时间 |
| 单轴与组合工况 | 先验证 X，再扩展 Y、Z、XYZ | 均测 ΔX、ΔY、ΔZ |
| 以参考热状态计算变化 | 每轮保留独立初始基准与同一标定版本 | 恢复时不重新清零 |
| 用独立记录检验结论 | 同工况不同次试验；建模时整轮留出 | 一个窗口内多点不算独立重复 |

以下具体时长、回测节拍和重复次数均为针对本装置提出的先导设计，不是参考论文原参数，也不是已验证的标准要求。文献里的五轴行程、进给速度和动态测量精度不能直接移用。

## 3. 先做测量链检查

### 3.1 装夹与标定

记录探头/仪表型号、量程、球径及材料、球杆长度、球心位置、三个探头方向、温度通道位置；拍整体和局部照片。装夹不变时使用对应标定矩阵 C；任何探头方向或球杆装夹变化后，应重新检查标定适用性。

在实际工作区内施加小幅 X、Y、Z 正负位移，核对三维输出的正负、通道顺序、线性范围与交叉响应。用未参与拟合的位移点检查残差。机床指令位移可用于方向和一致性检查，但不自动等于可溯源真值；若有独立位移表或激光测量，可增加对照并记录其性能。

历史 XYZ 末点 30 μm 差异尚未解释。新试验每个有效窗口同时保存原始探头值、基准、C、程序输出 XYZ 与离线复算 XYZ；先验证保存链，发现差异时保留现场文件。

### 3.2 两种重复性检查

| 检查 | 操作建议 | 保存内容 |
|---|---|---|
| 静止短时稳定性 | 球停在测点、主轴停转，连续记录约 30 min | 三探头、XYZ、18 路温度及真实时间 |
| 重复返回 | 在热状态尽量稳定时，按同一路径离开并返回，建议先做 20 次 | 每次窗口均值、窗口内波动、返回时间及主轴角向状态 |

返回试验采用正式实验同一最终接近方向、等待与采样窗口。记录开始和结束温度；若试验过程中出现明显慢漂移，分别报告慢漂移与返回离散，不能把总离散全部归于重复定位。

若正式加载含主轴旋转，还应做包含“退离—旋转—停转—定向—回测”的短循环检查。仅做主轴始终停转的返回试验，不能覆盖该流程的全部重复性。定向操作以本机控制器已有且经验证的功能为准。

不预先宣称系统达到某个微米精度。若返回离散与待观察热漂移相近，应先解决装夹、定向或测量问题，再延长热试验。

## 4. 第一轮 X 轴试验

### 4.1 固定条件

首轮优先沿用现有论文的主轴背景：运行时按固定转速 n0 旋转，回测时停转并保持一致角向状态。n0 必须由实际机床设定填写；不默认 6000 r/min。若决定专门研究主轴停转时的进给热效应，应另建“主轴全程停转”系列，不能与主轴旋转系列混为同一条件。

- 采用一个已经验证可运行的 X 轴速度、固定起终点及往复路径；首轮不切换速度。
- 分别记录 X 轴速度单位、实际行程、加减速设置、循环数及测量中断。XYZ 联动时另记路径进给和各轴运动分量。
- 均无新增分区水冷。机床原有主轴冷却、润滑及热补偿功能的状态保持一致并如实记录，不因“无水冷”而关闭制造商要求的系统。
- 球杆、探头架、测点、最终接近方向、仪器预热流程保持一致。
- 从充分停机后的状态开始，记录停机时长及起始温度；“隔夜”本身不证明已经达到热平衡。

### 4.2 时间安排

| 阶段 | 首轮建议 | 实际操作与目的 |
|---|---|---|
| 初始稳定观察 | 约 30 min | 采集初温、静止漂移；确认基准是否仍在显著变化 |
| 建立参考 | 加载前 | 保存冷态探头基准 p0、C、XYZ 零点和真实时间 |
| X 轴往复加载 | 先安排 120 min 墙钟时间 | 固定速度与行程；回测中断计入日志，另算累计实际运动时间 |
| 加载回测 | 名义每 10 min 一次 | 先停止加载，按固定流程回到同一测点；记录实际窗口时刻 |
| 停止加载事件 | 加载结束 | 记录停止进给、主轴停止及其他状态变化的各自真实时间 |
| 自然恢复观察 | 先安排 120 min | 主轴停转、无加载循环，保留必要测量移动 |
| 恢复回测 | 名义每 10 min 一次 | 不中途重新清零；持续记录三向残余漂移和温度 |

2 h 加载和 2 h 恢复用于先导观察，不能直接命名为“达到热稳态”或“完全冷却”。若末段还明显变化，后续正式方案应统一延长观察，并保留首轮原始时长。首次先完成一轮约 4.5 h 的主试验，标定和返回检查另计。

名义 10 min 为计划节拍；分析使用实际窗口中心时刻。每次回测造成的进给暂停、主轴停转和恢复运行均是加载方案的一部分。若回测耗时过长，可在先导后统一改节拍，并记录方案版本。

### 4.3 每次回测的顺序

1. 记录暂停加载时间；停止进给与主轴，执行统一的主轴角向复位。
2. 按已经验证的回测路径返回测点，保持相同的最终接近方向。
3. 到位后等待固定时间。可先沿用程序原设定 5 s；先导记录须验证其是否足够，不把 5 s 当成已证明的稳定时间。
4. 可先沿用 2 s 采样周期、每窗口 5 点；首末点跨度为 8 s。保存每点实际时间、三探头原始值、XYZ 与同时间温度。
5. 检查窗口是否超量程或出现趋势/突跳。异常窗口保留并加原因标签，不以补点覆盖。
6. 加载阶段回测后退离探头区域，再按验证流程恢复主轴与 X 轴运行；恢复阶段回测后回到预定停放状态。

测球退离、主轴旋转和探头架之间的路径应先经过现场验证，不能直接照搬另一台机床的行程或数控指令。本文件不生成可直接上机的 NC 程序。

## 5. 试验扩展顺序

先导通过后，建议逐步形成以下同协议试验。表中的 n0 是统一且实际记录的主轴转速，不代表各工况热输入相同。

| 编号 | 主加载状态 | 用途 |
|---|---|---|
| E0 | 主轴停转、无往复加载；保留相同测量节拍 | 观察环境、测量链和必要回测运动共同造成的背景 |
| S0 | 仅主轴按 n0 运行，进给仅为回测服务 | 描述旋转主轴背景；停转与回测安排匹配加载组 |
| X | 主轴 n0＋X 往复 | 首轮优先 |
| Y | 主轴 n0＋Y 往复 | 与 X 采用同一数据协议 |
| Z | 主轴 n0＋Z 往复 | 按本机已验证的速度与行程执行 |
| XYZ | 主轴 n0＋XYZ 联动 | 另存完整联动路径和运动分量 |

最先完成 X 一轮，再独立重复 X 一轮，检查能否复现。如果能够稳定获取数据，再做 S0/E0 与 Y、Z、XYZ。正式研究建议为核心工况争取至少 3 次独立运行作为起点，最终次数依据先导变异和研究问题决定；三次本身不保证统计功效。

每次应从可比较的热状态开始；不能把一天内依次做 X、Y、Z 的连续升温段当成三个独立冷态实验。正式重复尽量轮换工况顺序，完整保存环境差异。E0 不是纯环境真值，S0 也不能无条件从其他组中相减得到进给的独立贡献。不同轴的速度和循环数不同，不据峰值直接推算产热百分比。

现有软件字段不足时，可先另存一张事件日志；不必为了首轮实验立即重写采集程序。所有系统用同一时钟，或记录时钟偏差。

| 数据层 | 必须记录 |
|---|---|
| 每轮元数据 | 实验编号、日期、程序版本、C 版本、装夹/测点、p0、主轴及冷却/补偿状态、各轴路径速度、采样设置 |
| 连续数据 | 实际时间、18 路温度、3 路探头；离位/超程标记 |
| 事件日志 | 加载开始、每次暂停/返回/采样/重启、停止进给、停止主轴、恢复观察开始、异常与操作说明 |
| 窗口数据 | 窗口编号、所属阶段、起止与中心时间、原始点索引、探头均值/标准差、XYZ 原存/复算值 |
| 重复性记录 | 每次返回的 XYZ、角向状态、起止温度、是否发生慢漂移 |

建议编号：RTEST_X_R01_YYYYMMDD、RTEST_X_R02_YYYYMMDD。当天实际日期填写在文件内，避免按计划日期替代真实实验日期。

原始 Excel 和事件日志只读归档，清洗数据与图表另存。冷态 p0 一轮内保持不变；停机恢复是相对该基准的回归过程，不能在恢复起点重新置零后声称“回到冷态”。

## 8. 首轮分析与可写结论

对有效窗口按对应记录的 C 与 p0 计算：

Δx_k = C (p̄_k − p0)，r_k = sqrt(ΔX_k² + ΔY_k² + ΔZ_k²)。

首先画三向有符号位移、r、温度及真实事件线。离位连续记录不转换为有效三维热漂移，不用插值填成“连续实测”。

按固定加载时长、固定恢复时长报告三向残余及已观测峰值。停机瞬间无有效窗口时，分别注明实际测量相对停机的延迟，不把首次恢复样本当作严格的停机瞬时值。初期恢复中出现某方向继续漂移应如实保留。

窗口内标准差描述短时读数波动，返回离散描述整个返回流程在相应条件下的表现；二者都不等于总不确定度。独立试验用于评价复现性，不能把同窗口的 5 点或同一轮的几十个窗口当成几十次独立实验。

首轮不急于拟合复杂预测模型。待独立轮次充足后，若增加预测研究，按整轮实验划分训练和验证，避免相邻窗口随机拆分造成信息泄漏。

## 9. 上机前需填写的最少信息

- 实际主轴转速 n0，以及停转/定向方式。
- X 往复起终点、速度及单位。
- 实际球心测量坐标与最终接近方向。
- 18 路温度的实物位置、现用标定 C 与采集程序版本。

这些未知量保持待填，不从历史文件名或其他机床论文补写。
