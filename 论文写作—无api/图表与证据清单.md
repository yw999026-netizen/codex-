## 目前可以写的结果

- 54 个窗口的点数、探头均值和三向窗口标准差在文件内部可复现；这不证明全部物理精度。
- 描述各记录的带符号 XYZ 和三维综合幅值，指出交叉方向响应。
- 说明温度下降与某方向位移减小并非必然同步，停机分界未明时只称末段现象。
- 说明数据处理一致性对 XYZ 记录观测峰值和趋势解释的影响。

## 目前不能作为结果的内容

结构区域产热百分比、Shapley 冷却贡献、八组合改善率、API 五点优越性以及预测/闭环控制性能均缺相应实验证据。不能把 54 个相关时间样本当成 54 次独立重复，也不能据四记录的不同峰值声称热输入相同。

## 最新事实确认

用户确认：四组运行期间主轴一直转动、回测时停转；停机分界待定；XYZ 末点无人工加 30 μm。主轴实际转速尚未提供，不将旧方案的 6000 r/min 自动套入四组。

X 文件有冷机相关列，但现有样本全部标为手动、轮次 0，不能据此确立停机分段。测球离位后的连续超程记录保留原始值，不作为连续 XYZ 漂移。

## 文献与创新表述

机床热误差基础参考 Mayr 等（2012），已核对题录及摘要。非接触 R-test 结构/标定参考 Jiang 等（2020），题录与摘要已在 [作者机构页面](https://researchportal.northumbria.ac.uk/en/publications/optimization-method-for-systematically-improving-non-contact-r-te/)核对；其研究对象并非本装置，不能作为本批标定验证替代。近期工况、热恢复与测量不确定度研究仍需补充全文阅读。

当前潜在贡献应围绕具体实验问题、数据可靠性与三维响应证据凝练，不把使用既有 R-test 原理本身宣称为首次发明。后续 API 论文应形成可检验的方法或控制贡献，设备品牌更换本身不构成充分创新。
