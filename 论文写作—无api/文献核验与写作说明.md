## 本版完成内容

将 v0.2 扩写为中英文摘要、引言、测量原理、实验记录与数据处理、结果分析、讨论及结论。保留四份无分区水冷记录及“运行时主轴旋转、回测时停转”的已确认条件。

正文以“固定测点三维热漂移表征”为主线，重点为交叉方向响应、三维幅值与单方向变化不同步，以及保存值/复算值差异对趋势判断的影响。上述内容属于本批记录支持的描述性结果，尚未建立新的热源分解方法或验证普适规律。

## 新增数值与复现范围

表 2 的首末窗口时间、表 3 的幅值与末点、表 4 的末两窗口增量，以及 X 组样本 22 → 25 的增量，均来自既有[窗口 CSV](分析结果/Rtest_有效窗口原值与复算值.csv)及[描述统计 CSV](分析结果/Rtest_四工况描述统计.csv)。

在仓库根目录运行：

    python 论文写作—无api/分析工具/verify_manuscript_metrics.py

脚本仅使用标准库，只读两份 CSV，将计算结果及输入 SHA-256 输出到标准输出，不生成或覆盖分析文件。它检查 54 个窗口的计数、时间换算、三维幅值、描述统计一致性及现有差异样本，然后输出正文新增指标。数值检查容差不代表物理测量精度。
